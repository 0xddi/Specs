# Техническое задание

## Основная задача и общие сведения
Создание лёгкого фронтенд WEB-приложения под названием GopherNote для хранения и управления заметками в Markdown разметке в chromium-based браузерах. Ориентирами являются известные приложения по типу Samsung Notes и Evernote. Уникальными функциями нашего решения являются система голосового ввода и система отображения мотивационных цитат в зависимости от контекста.

## Модули приложения и их техническая реализация

### Модель данных заметки
```js
{
  "Id": "00000000-0000-0000-0000-000000000000",
  "Title": "Some title, might even be empty",
  "Content": "Some content",
  "CreatedAt": "2026-06-02T00:00:00",
  "IsPinned": false,
  "Tags": ["tag1", "tag2", "tag3"],
  "Color": "#ffffff"
}
```

### Модуль MD-разметки (Markdown)
- **Назначение:** Трансформация сырого текстового контента заметки в валидный, безопасный HTML-код для его последующего отображения в режиме реального времени.
- **Спецификация синтаксиса:** Полная поддержка заголовков (`#`–`######`), стилизации текста (`**жирный**`, `*курсив*`, `~~зачеркнутый~~`), маркированных и нумерованных списков, блоков кода и горизонтальных линий (`---`).
- **QoL-функции для пользователей:**Автоматическая замена символа перехода на следуюшую строку (при нажатии Enter) на два пробела и символ перехода на следующую строку в соотв. с Markdown-синтаксисом

### Модуль голосового ввода (Speech-to-Text)
**Технологическая основа:** Браузерный Web Speech API, вызываемый из среды C# через механизм JavaScript Interop.

### Модуль контекстных цитат (QuoteService)
**Алгоритм анализа:** Мониторинг состояния локального хранилища и логов активности пользователя.  

#### Алгоритм и поведенческие триггеры `QuoteService`

Сервис `QuoteService` использует систему **нисходящего приоритета**. Это означает, что логика проверяет условия последовательно, начиная с наиболее критичных. Как только срабатывает первый подходящий триггер, метод возвращает соответствующую цитату и прекращает проверку остальных условий.

**Приоритет проверок (от высшего к низшему):**

1.  **Базовое состояние БД:**
    * `notes.Count == 0` -> *«Чистый лист — начало великих идей. Создайте свою первую заметку.»*
2.  **Реакция на «Возвращение»:**
    * `minutesSinceLastActivity < 1` и `daysSinceLastActivity > 3` -> *«С возвращением! Главное в продуктивности — это последовательность, а не скорость.»*
3.  **Защита от «Аналитического паралича»:**
    * `updatesInLastHour > 5` -> *«Прогресс идет полным ходом. Но не забывайте фиксировать мысли, а не бесконечно их полировать.»*
4.  **Проверка на выгорание:**
    * `notesCreatedToday > 10` -> *«Вы создали очень много заметок сегодня. Не забывайте об отдыхе — выгорание не дремлет.»*
5.  **Борьба с прокрастинацией:**
    * `daysSinceLastActivity > 7` -> *«Прокрастинация — вор времени. Давно мы не видели новых записей или правок!»*
6.  **Управление фокусом:**
    * `pinnedCount > 5` -> *«Слишком много приоритетов означает отсутствие приоритетов. Почистите закрепленные заметки.»*
7.  **Оптимизация структуры:**
    * `totalTags > 15` (при малом количестве заметок) -> *«У вас тегов больше, чем самих заметок. Возможно, пора упростить структуру?»*
8.  **Анализ стиля (Графомания):**
    * `avgContentLength > 2000` -> *«Ваши заметки похожи на главы из книг. Попробуйте выделить из них ключевые тезисы.»*
9.  **Контекст времени суток (Default):**
    * Если не сработал ни один из вышеперечисленных триггеров, сервис анализирует текущий час (`now.Hour`) и выдает сообщение, соответствующее биологическим часам пользователя (от «Доброе утро!» до «Ночь — время для сна»).

## Архитектура хранения данных (Локальная БД)
- **Общая концепция:** Использование системного объекта `localStorage` браузера пользователя. Приложение работает полностью автономно на стороне клиента без отправки контента на внешние сервера.
- **Сериализация:** Переход состояния объекта из памяти WebAssembly в постоянную память устройства осуществляется по цепочке:
  `C# Object (List<Note>)` -> `JsonSerializer.Serialize()` -> `JSON-строка` -> `js.InvokeVoidAsync("localStorage.setItem", ...)`

## Визульная часть карточек-заметок

### 1. Общие характеристики карточки (`.note-card`)
Все карточки имеют фиксированные параметры для поддержания сетки:
- **Размеры:** Ширина до 360px, высота фиксирована 320px.
- **Flex-структура:** Вертикальное расположение (заголовок, превью, теги, футер).
- **Оформление:** Скругление углов 14px, мягкая тень, скрытие переполнения контента (`overflow: hidden`).
- **Интерактив:** Плавный переход стилей при наведении (`transition: all 0.3s ease`).

---

### 2. Логика шаблонов (4 варианта)

Каждая карточка получает класс `.note-template-[1-4]`, определяющий её цветовую палитру:

| Шаблон | Стиль фона | Текст (Заголовок/Превью) | Акцент тегов |
| :--- | :--- | :--- | :--- |
| **№1** | Фиолетовый градиент | Белый / Полупрозрачный белый | Полупрозрачный (белый) |
| **№2** | Базовая тема (Светлая/Тёмная) | Основной цвет текста | Фон ввода (`--bg-input`) |
| **№3** | Тёмно-синий градиент | Светло-голубой / Серый | Тёмно-синий (полупрозр.) |
| **№4** | Тёмно-зелёный градиент | Бледно-бирюзовый / Зеленоватый | Тёмно-зеленый (полупрозр.) |

---

### 3. Компоненты карточки

#### 3.1. Заголовок (`.note-header`)
- Содержит кнопку закрепа (`.pin-icon`) и заголовок `h4`.
- **Закреп:** При состоянии `IsPinned` активируется класс `.pinned-style`, добавляющий яркую белую рамку (2px) и свечение, выделяя карточку в сетке.
- **Текст:** Обрезается при переполнении с помощью `text-overflow: ellipsis`.

#### 3.2. Превью (`.note-preview`)
- Ограничивает контент до 100 символов с добавлением многоточия.
- Использует кастомный узкий скроллбар (4px) с акцентным цветом (`--accent`) при прокрутке длинного текста внутри карточки.

#### 3.3. Система тегов (`.note-tags`)
- **Отображение:** Первые 5 тегов видны сразу.
- **Группировка:** Если тегов > 5, создается элемент `+ X`, раскрывающий `tooltip-grid` при наведении.
- **Тултип:** Сетка из 3 колонок. Позиционируется строго над/под кнопкой тегов.

---

### 4. Интерактивные элементы
- **Кнопка редактирования (`.btn-edit`):** Занимает всю ширину футера. Цвет кнопки адаптивен и зависит от выбранного шаблона карточки.
- **Анимации:** Все интерактивные элементы (кнопки, теги, тултипы) используют плавные переходы (`opacity`, `transform`, `background`) для обеспечения «премиального» отклика интерфейса.

---

### 5. Адаптивность и темы
- **Dark-theme:** Шаблон №2 автоматически адаптирует фон и границы под переменные CSS-темы.
- **Контекст:** Для шаблонов с градиентами (1, 3, 4) стили тултипов переопределяются для обеспечения максимальной читаемости текста на темном фоне.

### Требования к интерфейсу (UI/UX) и вёрстке

- **Стилистика:** Строгий минималистичный монохромный дизайн в тёмных тонах ("Notion / Evernote style"). Все элементы управления используют плоскую геометрию с аккуратными скруглениями (`border-radius: 8px–14px`), тонкими границами и мягкими тенями. Основной акцентный цвет — `#6366f1`.
- **Splash Screen (Экран загрузки):** Центрированный индикатор на монохромном фоне. Появляется до инициализации WebAssembly-окружения и загрузки данных из `localStorage`.
- **Контекстный баннер (TopQuote):** Адаптивный блок, расположенный над сеткой заметок. Отображает динамические цитаты от `QuoteService`, ранжированные по приоритету (от критических событий до контекстных советов по времени суток).
- **Боковая панель (Sidebar):** Статичный блок (320px). Содержит кнопку создания заметки, секцию фильтрации (поиск по тегам), сортировку и переключатель темы (`ThemeToggle`).
- **Карточка заметки (NoteCard):** 
  - *Шаблоны:* Поддерживает 4 визуальных шаблона (`note-template-1` — `note-template-4`) с разными цветовыми схемами (градиенты, минимализм).
  - *Заголовок:* Ограничен `white-space: nowrap`, усекается через `text-overflow: ellipsis`.
  - *Превью:* Обрезка до 100 символов. Использует кастомный узкий скроллбар (4px) с акцентным цветом для длинного контента.
  - *Система тегов:* Отображает до 5 видимых тегов. При превышении лимита создается элемент `+ X`, который при наведении раскрывает `tooltip-grid`. Тултип реализован через сетку (3 колонки) с «мостиком» для предотвращения мерцания при переходе курсора.
  - *Закрепление:* Класс `.pinned-style` добавляет яркую белую рамку (2px) и свечение, выделяя карточку.
  - *Компоновка:* Flex-контейнер гарантирует прижатие кнопок и тегов к нижней грани, обеспечивая единообразную высоту (320px).
- **Интерфейс редактирования (EditNote):**
  - *Двухпанельная топология:* Деление 1:1. Левая панель — ввод Markdown, правая — мгновенный рендеринг (`MarkdownView`).
  - *Live Preview:* Синхронизация фона панели предпросмотра при смене цветового селектора в реальном времени.
  - *Управление тегами:* Гибридный ввод (кнопка + `Enter`). Добавленные теги отображаются как плашки с кнопкой удаления.
  - *Голосовой ввод:* Кнопка с цветовой индикацией состояния (черный — ожидание, красный — запись). Отображение промежуточного текста (`interimText`) в реальном времени.
