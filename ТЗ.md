# Техническое задание

## Основная задача и общие сведения
Создание лёгкого фронтенд WEB-приложения под названием GopherNote для хранения и управления заметками в Markdown разметке в chromium-based браузерах. Ориентирами являются известные приложения по типу Samsung Notes и Evernote. Уникальными функциями нашего решения являются система голосового ввода и система отображения мотивационных цитат в зависимости от контекста.

## Стек технологий
- Основной фреймворк: C# Blazor с компиляцией в WebAssembly

## Конкретный функционал приложения
- CRUD-функционал для заметок
  - Создание заметки при нажатии кнопки "Новая заметка" на главной странице
  - Отображения полного содержания заметки при нажатии кнопки "Редактировать"
  - Обновление заметки в соотв. режиме редактирования при нажатии кнопки "Редактировать" и "Сохранить" после проведённых изменений
  - Удаление через кнопку "Удалить" в режиме редактирования
- Возможность закрепления заметки для быстрого доступа к ней (закреплённая заметка должна находиться в самом верху списка всех созданных заметок; одновременно закреплённые заметки располагаются в порядке, установленном действующей сортировкой, т.е. "Сначала новые" или "Сначала старые") 
- Возможность назначать теги и выполнять поиск заметок по ним (поиск производится по всем вхождениям)
- Возможность выбрать цвет для заметки путём выбора одного из 4-х представленных шаблонов (для каждого экземляра заметки отдельно; по дефолту выбирается шаблон, соответствующий теме всего приложения)
- Шаблоны-заготовки для визуала заметок (4 штуки)
- Фильтр заметок по вышеупомянутым тегам (фильтрация производится по всем вхождениям)
- Сортировка по дате создания заметки ("Сначала новые" и "Сначала старые"; по дефолту "Сначала новые")
- Возможность голосового ввода содержимого заметки (при этом с одновременной возможностью ручной печати, т. е. прямо во время голосового ввода содержания заметки пользователь может печатать любые символы одновременно с этим)  
- Система отображения мотивационных цитат против прокрастинации/переутруждения в зависимости от действий пользователя (удаления заметок, время создания заметок, количество новосозданных заметок и т.д.)
- Список участников проекта с подписанными должностями в сайдбаре слева с ссылками на соответствующие гитхаб-аккаунты

## Модули приложения и их техническая реализация

### Модель данных заметки
```js
{
  "Id": "00000000-0000-0000-0000-000000000000",
  "Title": "Some title, might even be empty",
  "Content": "Some content",
  "CreatedAt": "2026-06-02T00:00:00",
  "IsPinned": false,
  "Tags": ["tag1", "tag2", "tag3"],
  "Color": "#ffffff"
}
```

### Модуль MD-разметки (Markdown)
- **Назначение:** Трансформация сырого текстового контента заметки в валидный, безопасный HTML-код для его последующего отображения в режиме реального времени.
- **Спецификация синтаксиса:** Полная поддержка заголовков (`#`–`######`), стилизации текста (`**жирный**`, `*курсив*`, `~~зачеркнутый~~`), маркированных и нумерованных списков, блоков кода и горизонтальных линий (`---`).
- **QoL-функции для пользователей:** Автоматическая замена символа перехода на следуюшую строку (при нажатии Enter) на два пробела и символ перехода на следующую строку в соотв. с Markdown-синтаксисом.

### Модуль голосового ввода (Speech-to-Text)
**Технологическая основа:** Браузерный Web Speech API, вызываемый из среды C# через механизм JavaScript Interop.

### Модуль контекстных цитат (QuoteService)
**Алгоритм анализа:** Мониторинг состояния локального хранилища и логов активности пользователя.  

#### Алгоритм и поведенческие триггеры `QuoteService`

Сервис `QuoteService` использует систему **нисходящего приоритета**. Это означает, что логика проверяет условия последовательно, начиная с наиболее критичных. Как только срабатывает первый подходящий триггер, метод возвращает соответствующую цитату и прекращает проверку остальных условий.

**Приоритет проверок (от высшего к низшему):**

1.  **Базовое состояние БД:**
    * `notes.Count == 0` -> *«Чистый лист — начало великих идей. Создайте свою первую заметку.»*
2.  **Реакция на «Возвращение»:**
    * `minutesSinceLastActivity < 1` и `daysSinceLastActivity > 3` -> *«С возвращением! Главное в продуктивности — это последовательность, а не скорость.»*
3.  **Защита от «Аналитического паралича»:**
    * `updatesInLastHour > 5` -> *«Прогресс идет полным ходом. Но не забывайте фиксировать мысли, а не бесконечно их полировать.»*
4.  **Проверка на выгорание:**
    * `notesCreatedToday > 10` -> *«Вы создали очень много заметок сегодня. Не забывайте об отдыхе — выгорание не дремлет.»*
5.  **Борьба с прокрастинацией:**
    * `daysSinceLastActivity > 7` -> *«Прокрастинация — вор времени. Давно мы не видели новых записей или правок!»*
6.  **Управление фокусом:**
    * `pinnedCount > 5` -> *«Слишком много приоритетов означает отсутствие приоритетов. Почистите закрепленные заметки.»*
7.  **Оптимизация структуры:**
    * `totalTags > 15` (при малом количестве заметок) -> *«У вас тегов больше, чем самих заметок. Возможно, пора упростить структуру?»*
8.  **Анализ стиля (Графомания):**
    * `avgContentLength > 2000` -> *«Ваши заметки похожи на главы из книг. Попробуйте выделить из них ключевые тезисы.»*
9.  **Контекст времени суток (Default):**
    * Если не сработал ни один из вышеперечисленных триггеров, сервис анализирует текущий час (`now.Hour`) и выдает сообщение, соответствующее биологическим часам пользователя (от «Доброе утро!» до «Ночь — время для сна»).

## Архитектура хранения данных (Локальная БД)
- **Общая концепция:** Использование системного объекта `localStorage` браузера пользователя. Приложение работает полностью автономно на стороне клиента без отправки контента на внешние сервера.
- **Сериализация:** Переход состояния объекта из памяти WebAssembly в постоянную память устройства осуществляется по цепочке:
  `C# Object (List<Note>)` -> `JsonSerializer.Serialize()` -> `JSON-строка` -> `js.InvokeVoidAsync("localStorage.setItem", ...)`

## Визуальная часть карточек-заметок

### 1. Общие характеристики карточки (`.note-card`)
Все карточки имеют строго фиксированные параметры для поддержания предсказуемой и адаптивной сетки:
- **Размеры:** Ширина до `360px`, высота жестко зафиксирована на `320px`. Для предотвращения деформации flex-контейнеров установлены свойства `min-width: 0`, `min-height: 0`, а также `box-sizing: border-box`.
- **Flex-структура:** Вертикальное независимое расположение элементов (`flex-direction: column`) с распределением пространства. Контент верхнего уровня защищен от переполнения с помощью `overflow: hidden`.
- **Оформление:** Скругление углов `14px`, рамка `1px solid var(--border-light)`, мягкая тень карточки `var(--shadow-card)`.
- **Интерактив:** Плавный переход стилей при изменении темы, цвета рамок и текста (`transition: background-color 0.2s ease, border-color 0.2s ease, color 0.2s ease`).

---

### 2. Шаблоны для карточек-заметок
Карточки используют системные CSS-переменные темы и делятся на шаблоны:


| Шаблон | CSS-класс | Поведение фона | Название |
| :--- | :--- | :--- | :--- |
| **№1** | `.note-template-1` | Фиолетовый градиентный фон | Классический |
| **№2** | `.note-template-2` | Обыкновенный тёмный фон, соотв. основной теме всего приложения | Минимализм |
| **№3** | `.note-template-3` | Тёмно-синий градиентный фон  | Акцент |
| **№4** | `.note-template-4` | Тёмно-зеленый градиентный фон | Элегантный |

### 3. Компоненты карточки

#### 3.1. Заголовок (`.note-header`)
- Представляет собой flex-строку с центрированием по вертикали и фиксированным отступом `gap: 10px`.
- **Иконка закрепа (`.pin-icon`):** Интерактивный элемент на основе символов: **★** (закреплено) и **☆** (отвязано). Имеет встроенный обработчик клика `@onclick="TogglePin"`.
- **Логика закрепа (`.pinned-style`):** При состоянии `Note.IsPinned = true` карточка получает класс `.pinned-style`. Она выделяется акцентной рамкой `border-color: var(--accent)` и приобретает мягкое фирменное свечение: `box-shadow: 0 10px 25px -5px rgba(99, 102, 241, 0.1)`.
- **Текст заголовка (`h4`):** Занимает оставшееся пространство строки, имеет ограничения на переполнение.

#### 3.2. Превью контента (`.note-preview`)
- **Ограничение объема:** Строго на уровне C#-кода строка обрезается до **100 символов** с автоматическим добавлением многоточия.
- **Безопасность и рендеринг:** Текст передается в компонент `<MarkdownView />`, который парсит Markdown через Markdig, отключая поддержку сырых HTML-тегов (`.DisableHtml()`) для предотвращения XSS-атак.

#### 3.3. Лимиты и архитектура системы тегов (`.note-tags`)
Для исключения выхода элементов за пределы фиксированной высоты карточки:
1. **Лимиты отображения:** - `maxVisibleTags = 5` — максимальное количество видимых тегов.
   - `maxTotalTags = 11` — абсолютный лимит (видимые + скрытые в тултипе).
2. **Элемент «Еще» (`.tag-more`):** Если тегов > 5, рендерится кнопка вида `+ X` (где X — количество скрытых тегов).
3. **Выпадающий список (`.tooltip-grid`):** - Позиционируется абсолютно (`position: absolute`). 
   - По умолчанию скрыт (`opacity: 0`, `visibility: hidden`), показывается плавно при наведении.
   - Снабжен кастомным вебкит-скроллбаром (ширина `6px`, скругление `8px`).

---

### 4. Интерактивные элементы и футер (`.note-footer`)
- **Кнопка «Редактировать» (`.btn-edit`):** Находится в нижней части карточки. При нажатии вызывает событие `@onclick="EditNote"` для открытия формы редактирования.
- **Анимации:** Время анимации наведения (`:hover`) `0.2s` для высокой отзывчивости.

## Требования к интерфейсу (UI/UX) и вёрстке

- **Стилистика:** Строгий минималистичный монохромный дизайн в тёмных тонах ("Notion / Evernote style"). Все элементы управления используют плоскую геометрию с аккуратными скруглениями (`border-radius: 8px–14px`), тонкими границами и мягкими тенями. Основной акцентный цвет — `#6366f1`.
- **Splash Screen (Экран загрузки):** Центрированный индикатор на монохромном фоне. Появляется до инициализации WebAssembly-окружения и загрузки данных из `localStorage`.
- **Контекстный баннер (TopQuote):** Адаптивный блок, расположенный над сеткой заметок. Отображает динамические цитаты от `QuoteService`, ранжированные по приоритету (от критических событий до контекстных советов по времени суток).
- **Боковая панель (Sidebar):** Статичный блок (320px). Содержит кнопку создания заметки, секцию фильтрации (поиск по тегам), сортировку и переключатель темы (`ThemeToggle`).
- **Карточка заметки (NoteCard):** 
  - *Шаблоны:* Поддерживает 4 визуальных шаблона (`note-template-1` — `note-template-4`) с разными цветовыми схемами (3 градиента).
  - *Заголовок:* Ограничен `white-space: nowrap`, усекается через `text-overflow: ellipsis`.
  - *Превью:* Обрезка до 100 символов. Использует кастомный узкий скроллбар (4px) с акцентным цветом для длинного контента.
  - *Система тегов:* Отображает до 5 видимых тегов. При превышении лимита создается элемент `+ X`, который при наведении раскрывает `tooltip-grid`.
  - *Закрепление:* Класс `.pinned-style` добавляет яркую белую рамку (2px) и свечение, выделяя карточку.
  - *Компоновка:* Flex-контейнер гарантирует прижатие кнопок и тегов к нижней грани, обеспечивая единообразную высоту (320px).
- **Интерфейс редактирования (EditNote):**
  - *Двухпанельная топология:* Деление 1:1. Левая панель — ввод Markdown, правая — мгновенный рендеринг (`MarkdownView`).
  - *Управление тегами:* Добавленные теги отображаются как плашки с кнопкой удаления.
  - *Голосовой ввод:* Кнопка с цветовой индикацией состояния (фиолетово-синий `#6366f1` — ожидание, красный — запись). Отображение промежуточного текста (`interimText`) в реальном времени внизу левой панели ввода.
