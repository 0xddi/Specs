# Техническое задание

## Основная задача и общие сведения
Создание лёгкого фронтенд WEB-приложения под названием GopherNote для хранения и управления заметками в Markdown разметке в chromium-based браузерах. Ориентирами являются известные приложения по типу Samsung Notes и Evernote. Уникальными функциями нашего решения являются система голосового ввода и система отображения мотивационных цитат в зависимости от контекста.

## Конкретный функционал приложения
- CRUD-функционал для заметок
  - Создание заметки при нажатии кнопки "Новая заметка" на главной странице
  - Отображения полного содержания заметки при нажатии кнопки "Редактировать"
  - Обновление заметки в соотв. режиме редактирования при нажатии кнопки "Редактировать" и "Сохранить" после проведённых изменений
  - Удаление через кнопку "Удалить" в режиме редактирования
- Возможность закрепления заметки для быстрого доступа к ней  
- Возможность назначать теги и выполнять поиск заметок по ним  
- Возможность выбрать цвет для заметки (белый, серый, светло-серый)
- Возможность переключаться между светлой и тёмной темой (обе эти темы применяются к вышеобозначенным трём цветам заметки)
- Фильтр заметок по вышеупомянутым тегам
- Сортировка по дате создания заметки ("Сначала новые" и "Сначала старые")
- Возможность голосового ввода содержимого заметки (при этом с одновременной возможностью ручной печати, т. е. прямо во время голосового ввода содержания заметки пользователь может печатать любые символы одновременно с этим)  
- Система отображения мотивационных цитат против прокрастинации/переутруждения в зависимости от действий пользователя (удаления заметок, время создания заметок, количество новосозданных заметок и т.д.)

## Модули приложения и их техническая реализация

### Модель данных заметки
```js
{
  "Id": "00000000-0000-0000-0000-000000000000",
  "Title": "Some title, might even be empty",
  "Content": "Some content",
  "CreatedAt": "2026-06-02T00:00:00",
  "IsPinned": false,
  "Tags": ["tag1", "tag2", "tag3"],
  "Color": "#ffffff"
}
```

### Модуль MD-разметки (Markdown)
- **Назначение:** Трансформация сырого текстового контента заметки в валидный, безопасный HTML-код для его последующего отображения в режиме реального времени.
- **Спецификация синтаксиса:** Полная поддержка заголовков (`#`–`######`), стилизации текста (`**жирный**`, `*курсив*`, `~~зачеркнутый~~`), маркированных и нумерованных списков, блоков кода, цитат (`>`) и горизонтальных линий (`---`).

### Модуль голосового ввода (Speech-to-Text)
- **Технологическая основа:** Браузерный Web Speech API, вызываемый из среды C# через механизм JavaScript Interop.

### Модуль контекстных цитат (QuoteService)
- **Алгоритм анализа:** Мониторинг состояния локального хранилища и логов активности пользователя.  

- **Алгоритм и поведенческие триггеры:**
  - Пустая БД (`notes.Count == 0`) -> Выдача приветственной цитаты для старта: *«Чистый лист — начало великих идей. Создайте свою первую заметку.»*
  - Гиперактивность (`notesCreatedToday > 10`) -> Выдача цитат о предотвращении переутомления: *«Вы создали очень много заметок сегодня. Не забывайте об отдыхе — выгорание не дремлет.»*
  - Прокрастинация (`daysSinceLastNote > 7`) -> Выдача триггерных цитат, мотивирующих преодолеть лень: *«Прокрастинация — вор времени. Давно мы не видели новых записей!»*
  - Перегрузка фокуса (`pinnedCount > 5`) -> Выдача цитат для борьбы с ложной многозадачностью: *«Слишком много приоритетов означает отсутствие приоритетов. Почистите закрепленные заметки.»*
  - Стандартное состояние (Default) -> Выдача базовой фоновой мотивации: *«Продуктивность — это не делать больше, а делать то, что важно.»*

## Архитектура хранения данных (Локальная БД)
- **Общая концепция:** Использование системного объекта `localStorage` браузера пользователя. Приложение работает полностью автономно на стороне клиента без отправки контента на внешние сервера.
- **Сериализация:** Переход состояния объекта из памяти WebAssembly в постоянную память устройства осуществляется по цепочке:
  `C# Object (List<Note>)` -> `JsonSerializer.Serialize()` -> `JSON-строка` -> `js.InvokeVoidAsync("localStorage.setItem", ...)`

## Требования к интерфейсу (UI/UX) и вёрстке в целом

- **Стилистика:** Строгий минималистичный монохромный дизайн в тёмных и светлых тонах ("Notion / Evernote style"). Все элементы управления используют плоскую геометрию с аккуратными скруглениями углов (`border-radius: 8px–16px`), тонкими границами и мягкими тенями для создания ощущения легкости и фокуса на текстовом контенте.
- **Splash Screen (Экран загрузки):** Центрированный индикатор загрузки на монохромном фоне. Появляется до полной инициализации WebAssembly-окружения и асинхронного считывания JSON-массива из `localStorage`.
- **Контекстный баннер цитат (TopQuote):** Растянутый на всю ширину рабочей области адаптивный блок с акцентными вертикальными границами слева и справа. Служит для вывода динамических текстовых уведомлений от `QuoteService`. Располагается над основной сеткой заметок и сайдбаром.
- **Боковая панель управления (Sidebar):** Статичный вертикальный блок фиксированной ширины (320px). Содержит главную кнопку создания новой записи, изолированную секцию фильтрации (поиск по тегам с динамическим обновлением реестра по событию `oninput` и селектор направления сортировки), а также интегрированный в нижнюю часть переключатель цветовой схемы (ThemeToggle).
- **Карточка заметки (NoteCard):** 
  - *Защита от переполнения заголовка:* Поле названия имеет жесткое ограничение `white-space: nowrap`. При превышении физической ширины карточки текст аккуратно усекается маской `text-overflow: ellipsis`.
  - *Конвейер превью контента:* Сырой Markdown-текст программно обрезается до 100 символов с конкатенацией многоточия `...`. Для исключения деформации сетки сверхдлинными словами (например, неразрывными URL-ссылками) к блоку превью принудительно применяются свойства автоматического переноса: `word-wrap: break-word` и `word-break: break-word`.
  - *Позиционирование тегов и футера:* Блок прикрепленных ключевых слов (тегов) вынесен из подвала и позиционируется строго над кнопкой «Редактировать». Контейнер тегов использует `flex-wrap: wrap` для корректного многорядного отображения при большом количестве меток. За счет свойства `flex-grow: 1` у блока превью, теги и кнопка всегда прижимаются к нижней грани, гарантируя идеально ровную высоту карточек в сетке `notes-grid`.
  - *Цветовая индикация:* Карточка динамически переключает классы фона (`bg-white`, `bg-light-gray`, `bg-gray`) в зависимости от метаданных модели. Закрепленные заметки (`IsPinned`) выделяются по периметру контрастной рамкой основного акцентного цвета.
- **Интерфейс редактирования (EditNote):**
  - *Двухпанельная топология:* Экран разделен на две симметричные вертикальные зоны (Grid: `1fr 1fr`). Левая панель отведена под интерактивное текстовое поле ввода (`textarea`) с моноширинным шрифтом для написания Markdown. Правая панель (`md-preview`) служит для мгновенного рендеринга итогового HTML-дерева через компонент `MarkdownView`.
  - *Реактивность Live Preview:* Панель предпросмотра синхронизирует цвет своего фона инлайново в режиме реального времени при переключении селектора цветов в тулбаре, не требуя сохранения или перезаписи объекта в БД.
  - *Инструменты управления тегами (UX-оптимизация):* Панель инструментов включает компактное текстовое поле для ввода новых меток. Система поддерживает бесшовный гибридный ввод тега: как по клику на физическую кнопку «Добавить», так и по нажатию клавиши `Enter` прямо из поля ввода за счет связывания событий клавиатуры `@onkeyup` и мгновенной реактивности `@bind:event="oninput"`. Добавленные теги рендерятся внутри редактора в виде компактных плашек с индивидуальной кнопкой удаления («×»).
  - *Голосовой ввод:* Кнопка активации аудио-потока динамически переключает цветовой статус (контрастный черный в режиме ожидания, сигнальный красный `btn-danger` в режиме записи) и выводит интерактивную строку промежуточного распознавания речи (`interimText`) под курсором ввода.
